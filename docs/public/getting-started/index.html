Getting Started

Getting Started with Focus Helper

This guide will help you get Focus Helper up and running quickly on your system.

Prerequisites

Before installing Focus Helper, ensure you have:

  • Go 1.21+ (for building from source)
  • CMake (for building Whisper.cpp)
  • PortAudio (for audio support)
  • ALSA/OSS (Linux audio system)
  • Git (for cloning the repository)

Installing Dependencies

Ubuntu/Debian

1sudo apt update
2sudo apt install -y golang-go cmake build-essential portaudio19-dev libasound2-dev

macOS

1# Install Homebrew if you haven't already
2/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
3
4# Install dependencies
5brew install go cmake portaudio

Windows

1# Install Chocolatey if you haven't already
2Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
3
4# Install dependencies
5choco install golang cmake portaudio

Installation

Option 1: Build from Source (Recommended)

  1. Clone the repository:

    1git clone https://github.com/robertocpaes/focus-helper.git
2cd focus-helper

  2. Build the application:

    1make build

  3. Install to system:

    1make move

Option 2: Docker (Alternative)

  1. Build Docker image:

    1docker build -t focus-helper .

  2. Run with Docker Compose:

    1docker-compose up --build

First Run

Basic Usage

Start Focus Helper with default settings:

1focushelper

With MCP Server

Enable the MCP server for external integration:

1focushelper --mcp

Docker Mode

Run in Docker-compatible mode:

1focushelper --docker

Microphone Selection

Force microphone selection on startup:

1focushelper --select-microphone

Initial Configuration

1. Microphone Setup

On first run, Focus Helper will prompt you to select a microphone:

🎤 Microphone Selection
Available input devices:
[0] HDA Intel PCH: ALC1220 Analog (Input Channels: 2, DefaultSampleRate: 48000)
[1] USB Audio Device (Input Channels: 1, DefaultSampleRate: 44100)
Select input device by number: 0

2. Voice Commands

Focus Helper comes with pre-configured voice commands:

  • Activation: “torre controle comando” (Portuguese)
  • Emergency: “mayday emergencia”
  • Stop: “parar para cancela”
  • Status: “tempo horas atividade”
  • Check: “check checagem status”

3. Alert Levels

Default alert levels are configured as:

Level Duration Description
Low 45 minutes Basic break reminder
Medium 90 minutes More urgent reminder
High 3 hours Strong intervention needed
Critical 6 hours Emergency intervention

Configuration Files

Focus Helper stores configuration in:

  • Linux/macOS: ~/.config/focushelper/
  • Windows: %APPDATA%\focushelper\

Main Configuration

Edit profiles.json to customize:

 1{
 2  "default": {
 3    "alert_levels": [
 4      {
 5        "enabled": true,
 6        "level": "low",

Testing the Installation

1. Check Health Status

1curl http://localhost:8088/health

Expected response:

1{"status": "healthy", "service": "focus-helper"}

2. Test MCP Server

1curl http://localhost:8089/health

Expected response:

1{"status": "healthy", "service": "focus-helper-mcp"}

3. Test Voice Commands

  1. Say the activation phrase: “torre controle comando”
  2. Wait for the system to respond
  3. Try a command like “tempo horas atividade”

4. Test Alert Triggering

1curl -X POST http://localhost:8089/mcp \
2  -H "Content-Type: application/json" \
3  -d '{"jsonrpc":"2.0","id":1,"method":"trigger_alert","params":{"alert_index":0}}'

Troubleshooting

Common Issues

Audio Not Working

1# Check audio devices
2arecord -l
3
4# Test microphone
5arecord -f cd -d 5 test.wav
6aplay test.wav

Permission Denied

1# Add user to audio group (Linux)
2sudo usermod -a -G audio $USER
3# Log out and back in

Port Already in Use

1# Check what's using the port
2sudo netstat -tulpn | grep :8088
3sudo netstat -tulpn | grep :8089
4
5# Kill the process
6sudo kill -9 <PID>

Build Errors

1# Clean and rebuild
2make clean
3make build
