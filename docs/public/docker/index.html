Docker Support

Docker Support

Focus Helper provides comprehensive Docker support for easy deployment and cross-platform compatibility.

Overview

Docker support enables:

  • Cross-Platform Deployment: Run on any Docker-supported platform
  • Easy Setup: One-command deployment
  • Audio Support: Full audio device access in containers
  • Flexible Configuration: Environment-based configuration
  • Production Ready: Scalable containerized deployment

Quick Start

Using Docker Compose (Recommended)

  1. Clone the repository:

    1git clone https://github.com/robertocpaes/focus-helper.git
2cd focus-helper

  2. Start with Docker Compose:

    1docker-compose up --build

  3. Run in background:

    1docker-compose up -d --build

Using Docker Directly

  1. Build the image:

    1docker build -t focus-helper .

  2. Run the container:

    1docker run -d \
2  --name focus-helper \
3  --device /dev/snd:/dev/snd \
4  --privileged \
5  --group-add audio \
6  -p 8088:8088 \
7  -p 8089:8089 \
8  focus-helper

Multi-Stage Build

 1# Multi-stage build for focus-helper
 2FROM golang:1.21-alpine AS builder
 3
 4# Install build dependencies
 5RUN apk add --no-cache \
 6    gcc \
 7    g++ \
 8    make \
 9    cmake \
10    pkgconfig \
11    alsa-lib-dev \
12    portaudio-dev \
13    ffmpeg-dev
14

16WORKDIR /app
17
18# Copy go mod files
19COPY go.mod go.sum ./
20
21# Download dependencies
22RUN go mod download
23
24# Copy source code
25COPY . .
26
27# Build the application
28RUN make build
29
30# Runtime stage
31FROM alpine:latest
32
33# Install runtime dependencies
34RUN apk add --no-cache \
35    alsa-lib \
36    portaudio \
37    ffmpeg \
38    sox \
39    pulseaudio-utils
40
41# Create app user
42RUN adduser -D -s /bin/sh focushelper
43
44# Set working directory
45WORKDIR /app
46
47# Copy built binary
48COPY --from=builder /app/focushelper /usr/local/bin/focushelper
49
50# Copy configuration files
51COPY --from=builder /app/profiles.json /app/profiles.json
52COPY --from=builder /app/langs /app/langs

69ENV FOCUSHELPER_DOCKER_MODE=true
70
71# Expose ports

73
74# Run the application in Docker mode
75CMD ["focushelper", "--docker"]

Audio Configuration

Linux Audio Support

For Linux systems, ensure proper audio device access:

1services:
2  focus-helper:
3    # ... other configuration
4    devices:
5      - "/dev/snd:/dev/snd"
6    privileged: true
7    group_add:
8      - audio

macOS Audio Support

For macOS, use PulseAudio:

1services:
2  focus-helper:
3    # ... other configuration
4    environment:
5      - OTO_DRIVER=pulseaudio
6      - PULSE_SERVER=${XDG_RUNTIME_DIR}/pulse/native
7    volumes:
8      - ${XDG_RUNTIME_DIR}/pulse/native:${XDG_RUNTIME_DIR}/pulse/native

Windows Audio Support

For Windows, use DirectSound:

1services:
2  focus-helper:
3    # ... other configuration
4    environment:
5      - OTO_DRIVER=directsound

Environment Variables

Core Configuration

Variable Default Description
FOCUSHELPER_DOCKER_MODE false Enable Docker-compatible mode
FOCUSHELPER_MCP_SERVER_ENABLED true Enable MCP server
FOCUSHELPER_MCP_SERVER_PORT 8089 MCP server port
FOCUSHELPER_DEBUG false Enable debug mode

Audio Configuration

Variable Default Description
OTO_DRIVER auto Audio driver to use
PULSE_SERVER - PulseAudio server (macOS)
ALSA_DEVICE - ALSA device (Linux)

Database Configuration

Variable Default Description
FOCUSHELPER_DATABASE_FILE /home/focushelper/.config/focushelper/focus_helper.db Database file path
FOCUSHELPER_LOG_FILE /home/focushelper/.config/focushelper/focus_helper.log Log file path

Troubleshooting

Common Issues

Audio Not Working

1# Check audio devices
2docker exec -it focus-helper ls -la /dev/snd/
3
4# Test audio device detection
5docker exec -it focus-helper focushelper --docker --select-microphone

Permission Denied

1# Check container permissions
2docker exec -it focus-helper id
3
4# Check audio group membership
5docker exec -it focus-helper groups

Port Already in Use

1# Check port usage
2sudo netstat -tulpn | grep :8088
3sudo netstat -tulpn | grep :8089
4
5# Kill conflicting processes
6sudo kill -9 <PID>

Debug Mode

1# Run with debug logging
2docker run -it --rm \
3  --device /dev/snd:/dev/snd \
4  --privileged \
5  --group-add audio \
6  -e FOCUSHELPER_DEBUG=true \
7  focus-helper focushelper --docker --debug

Logs

1# View container logs
2docker logs focus-helper
3
4# Follow logs in real-time
5docker logs -f focus-helper
6
7# View specific log files
8docker exec -it focus-helper tail -f /home/focushelper/.config/focushelper/focus_helper.log

Best Practices

  1. Use Docker Compose: Easier management and configuration
  2. Persistent Volumes: Store configuration and data persistently
  3. Resource Limits: Set appropriate memory and CPU limits
  4. Health Checks: Monitor container health
  5. Logging: Configure proper log rotation
  6. Security: Use least privilege principle
  7. Updates: Regular image updates for security
